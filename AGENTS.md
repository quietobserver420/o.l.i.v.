# O.L.I.V. (Omni Live Intelligence View) — Agentic Engineering Protocol

## 1. System Identity
O.L.I.V. is a 4D spatial intelligence, chronological cycle analysis (Ophis), and South Australian regional logistics platform built on Vue 3, CesiumJS, MapLibre GL, Vite, and the Google AI Ultra stack.

## 2. REA 5-Stage Integration Workflow (morluto/rea)
1. **Stage 1 (Recon):** Inspect target repository files and map dependencies before writing code.
2. **Stage 2 (Isolate):** Extract only the pure functional module, shader, or data parser required.
3. **Stage 3 (Adapt):** Wrap the extracted logic into `src/layers/`, `src/data/`, or `server/providers/` using native O.L.I.V. state patterns.
4. **Stage 4 (Verify):** Run `npm run build` to verify zero bundler or syntax regressions.
5. **Stage 5 (Commit):** Commit atomically with clear module attribution.
